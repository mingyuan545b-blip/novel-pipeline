# 压测项目方案：《调包》——以「腔调」为武力、以「归属过户」为规则

> **用途**：新建小说项目立项书 + 实体中心**全量压测载体**
> **待测面**：角色 / 编年史 / 限知 / 装备 / 功夫 / 线索 / 仆人 / 世界域 / 篇章节奏 / 人物道具世界归属绑定 / 带出条件 / 追溯定位校验 / 方言地域风格
> **状态**：方案（未开工）。落地按 sop/09（约束词）→ sop/12（工艺）→ sop/03/07（功能/Pipeline）
> **一句话**：这不是"顺便测一下系统"，而是**把每个待测系统做成世界的骨头**——系统一旦是剧情的主规则，测试用例就长在剧情上，不用硬编。

---

## 零、先说难听话：为什么不能随便挑个题材来压测

随便写个校园恋爱，你要测"副本带出政策"，就得硬塞一个副本进去——那是测试用例，不是小说；
反过来，题材自己会**绕过**系统的薄弱处：反正剧情不需要，谁也不会去点那个按钮。

《调包》反过来干：
- **方言 = 武力** → 不测方言注入，打斗就写不了；
- **归属绑定 = 生死** → 不测 `scopeWorldId/locationSlot/bindMedium`，角色连自己的兵器都拿不动；
- **带出政策 = 通关条件** → 不测 `carryOutGate`，副本根本走不出去。

于是**没有兜底空间**：系统崩了就是剧情崩，藏不住。这才是压测该有的狠劲。
代价也要说在前头：**这个盘子会把带出门禁、限知串知、编年史回流这几处最先顶崩**——那正是目的，但必须预留"软门禁 + 告警 + 显式债务"的路，别把自己卡死写不动。

## 一、题材元素（年轻向 · 反套路）

### 1.1 一句话概念

在一个人人靠"口音"吃饭的城市里，有个说话**没腔调**的年轻人，专干一件事：**给别人的东西"过户"**——
把归属、来路、身份，从一个主儿手上挪到另一个主儿手上。行话叫「调包」。

### 1.2 差异化卖点（别人没有的）

| | 别人的写法 | 这里的写法 |
|---|---|---|
| 声音 | 音波功/超声波，本质是"力气" | **产权**。一段腔调有主、有来路、有归属域，能抵押、能过户、能追溯、能被伪造 |
| 方言 | 人物标签（"带点东北味"） | **战斗流派本体**。粤腔、川腔、东北腔、闽南腔、客腔各有功法与破法 |
| 金手指 | 越强越好 | **负数**。主角在这个比口音的世界里**没有口音**——枪战片里唯一没枪的人。爽点全靠规则漏洞翻盘 |
| 战斗 | 比谁嗓门大 | 比**谁的"来路"更真**。你借来的腔，来路链一断，当场走音 |

### 1.3 主情绪与情绪配方

- **主情绪：智性爽**——没背景的人用规则玩死有背景的人。（这是上一本《逆江湖》被老书虫判"最漂亮"的东西，验证过，接着用。）
- 配方（**必须有主味，禁止均匀撒糖**；紧张场景笑点归零）：

| 味 | 占比 | 什么时候给 |
|---|---|---|
| 智斗·爽 | 45% | 每次"调包"翻盘 |
| 悬疑 | 20% | 限知逐层揭示 |
| 燃 | 15% | 副本硬通、卷末 |
| 冷幽默（场景自适应） | 10% | 只给松弛场景，紧张场景=0 |
| 悲·代价 | 10% | 每次用"跑调"都当场兑现 |

### 1.4 主循环（读者每章想看什么）

> **接单 → 摸"来路" → 撞上归属/权限卡点 → 找规则漏洞过户 → 兑现代价 → 冷钩子收尾。**

可重复、每章换副本/换物/换权限类型——**正好逐章把带出六大策略轮一遍**。

### 1.5 节奏公式

- 每 **2 章**一个小反转；每 **3–5 章**一次完整翻盘；每 **卷**一次"大震撼"（限知升级）。
- 开篇铁律：前 1000 字必须同时出现**冲突 + 信息差 + 反常**。

### 1.6 禁忌（碰了就掉粉）

1. 不准把"腔"写成玄幻境界（"X 重天"）。腔是**社会性的**：地域、身份、圈子。
2. 不准让主角开挂碾人。**他每一次赢都要付代价**（走音 / 失忆 / 丢地域认同）。
3. 不准在紧张处抖机灵。（上一本翻车点，白纸黑字。）
4. 不准用"命运的齿轮 / 时代的洪流"收尾。章末落点必须是**具体物件或动作**。

### 1.7 题材落点（为什么用都市异能，而不是新造题材）

推荐**在现有 `high-martial-crossplane` 插件下新增分支 `urban-voice-dialect`**，而不是从零造题材。理由：
- 该插件的 `modules/`（`subPlaneSystem` / `cultivationSystem` / `supportingDepth`）**已经有小世界、穿越、装备阶段、配角深度的全套 schema**——`scopeWorldId`、`carryOutPolicy`、`stages` 这些正是压测目标，现成；
- 分支机制（`branches/`）已跑通，加一个分支的改动面最小、覆盖最全；
- 现代都市约束复用 `都市异能` 的 `constraintOverrides`（`modern-setting-consistency` / `ability-secrecy`），省一遍约束词设计。

## 三、世界观：规则卡（规则三问）

> **反例警告**：上一本的世界观素材 30 条几乎全是"XX 机制/XX 体系/XX 规则"——那是**设定集**，不是**世界观**。设定集只回答"是什么"；世界观要回答"读者能感觉到什么"。
> 所以下面每条规则都必须回答**三问**：*怎么进日常 / 谁执行·成本多大 / 边界在哪*。

### 规则 1 · 腔有主（归属）

- **进日常**：冼星宇借你一句粤腔去砍价，砍完这单，你欠他**一句**——他不催，账挂着，比高利贷还稳。
- **谁执行·成本**：""腔市"的老过户师（如郗伯）按"句"抽成；执行成本是**你自己的一段原话**（像押金）。
- **边界**：只有"开口说过"的腔才能过户；没出口的念头，无主，过不了户。

### 规则 2 · 来路可溯（追溯）

- **进日常**：夜市上买条二手渔鼓，扫码能扫出它**换过几手、在哪个域待过、上一个主儿是谁**——扫不出来的叫"脏货"，没人敢接。
- **谁执行·成本**：标音台的"回放员"负责查档，一次查档费**一段私密录音**。
- **边界**：跨域要留痕（`cross-world-traces` 的 `traceLog`）；**没留痕的跨界 = 串台 = 断货**，整条来路作废。

### 规则 3 · 带出要凭证（过户门禁）

- **进日常**：你把方言岛捡的一只猫带进城，楼道口机器响一声"渠道标签缺失"——猫被退回，你被罚走一段腔。
- **谁执行·成本**：各域的"出口"（`worldConstants` 的 `exitMethod` + `channelTag`）自动核验，通道成本 = **一段引唱**。
- **边界**：策略分六档（见 §五），每档要的凭据不同；**没有渠道标签的域，视同 `locked` 并告警，绝不静默放行**。

### 规则 4 · 说话即代价（代价前置）

- **进日常**：用腔发力会"走音"——说多了不是累，是**你的原声会淡一点**。城里很多人最后连自己是哪儿人都不记得了，还在说。
- **谁执行·成本**：没人执行，是**物理代价**。走音的账记在"母带"（席准的资本）那儿。
- **边界**：四阶往上（转调、跑调）代价陡增，跑调一次可能**永久失一段腔**。

### 规则 5 · 标准音会哑（主线谜面）

- **进日常**：某天早上，全城的"标准音"突然集体哑了——说普通话的人发不出声，说方言的人照常开口。
- **谁执行·成本**：表面是"标音台事故"（大众 `misinformed`），真凶藏在"高保真"的采集仓库里。
- **边界**：这正是**限知三维度**的主战场（见 §九）——同一件事，每个角色知道的程度和"信不信"都不一样。

## 五、世界域与副本矩阵（带出政策**六档全覆盖**）

> 对应测试：**世界域 / 归属绑定 / 带出条件（`evaluateCarryOut`）/ 渠道标签（`channelTag`）/ 追溯（`carried-out` 事件）**。
> 设计原则：**六个副本，把 `locked / native / medium / item / permission / plot` 各占一个**，写一章就打一次门禁。

| 副本（世界域） | 法则（一句话） | exitMethod（离开方式） | carryOutPolicy | channelTag（渠道标签） | 归属示例（scopeWorldId · locationSlot） |
|---|---|---|---|---|---|
| **主位面**（main-world） | 讲标准音的城市，平台说了算 | — | — | — | 默认主世界，位置空 |
| **拆迁楼·601** | 楼里不能报真名，报了会被"抹声" | 楼道声控灯连亮三下 | `medium`（需**逝主信物**） | 「退租凭证」 | 旧钥匙 → 601·3号房 |
| **录像厅·夜场** | 被镜头录到的人，下一场会重演自己 | 从放映口爬出 | `item`（需**票根**） | 「散场票」 | 老放映机 → 夜场·后仓 |
| **K 字头绿皮车厢** | 车上必须说邻座的口音，说错被"同化" | 到站开门 | `permission`（需**票根权限/乘务身份**） | 「补票章」 | 检票剪 → 车厢·7号座 |
| **腔市·夜摊** | 交易即绑定，反悔即失声 | 收摊铃 | `plot`（需**一次性授权/等价交换契约**） | 「收摊令」 | 渔鼓 → 夜摊·南三号 |
| **方言岛·围屋** | 外来腔会被同化，住下就再说不回原话 | 跨门槛 / 喝一碗擂茶 | `native`（原生物**可带出**） | 「围屋水牌」 | 拾音猫 → 围屋·天井 |
| **静音仓·直播间** | 发声即被采集，声音会变成平台资产 | 断线 | `locked`（**不可带出**） | *（无 → 视同锁定 + 告警）* | 变声卡 → 静音仓·B2 隔间 |
| **回音壁·大合唱**（终卷） | 所有人的腔在这里汇总，只能进不能出 | 唱完一支歌 | `plot + permission` 复合 | 「合唱歌单」 | 母带 → 回音壁·中枢 |

**门禁对抗用例**（故意让主角"白拿"）：
- 在 **拆迁楼**无条件把 NPC 的旧钥匙带走 → 应 **HARD BLOCK**（缺 `medium` 信物）；
- 补上逝主信物 + `channelTag` → 应 **放行**，并在 `cross-world-traces.traceLog` 留一条带 `channel/medium` 的 `carried-out`；
- 在 **静音仓** 试图把变声卡带出 → 应 **锁定 + 告警**（不得静默）；
- 把 **方言岛** 的原生猫带出 → 应 **放行（native）**，用来做"反例"，证明门禁不是无脑拦。

### 6.4 方言落库方式（**反刻板印象**）

**别手写音译。** 走系统既有链路，把方言做成"**语感锚点**"，不是"全程塑料方言"：
- 每人挂 `defaultDialects`（用 `data/dialects/*.json`：北京/东北/福建/广东/河南/客家/四川/上海…）；
- 只吃**句尾语气词 + 称呼 + 用词替换**（如东北"整/得劲"、粤语"收风"、闽南"拍谢"）；
- **禁用**"全程谐音字幕"式写法，防止与 `detectors`（网络用语/现代梗）打架，也防地域刻板印象。
- 验收：每个角色的方言在**跨章抽检**里保持一致（见 §十一 T13）。

## 九、线索与限知（三维度矩阵）

> 对应测试：**线索 / 限知（`factId × entityId × confidence × sourceHow`）/ 限知树 / 串知检测**。
> 系统定义：`confidence ∈ {certain, suspect, misinformed, unknown}`，`sourceHow ∈ {witnessed, told, inferred, discovered}`。

核心谜「**标准音失声案**」拆成 6 条 `fact`，**给不同角色不同确信度和来源**——一张表把限知所有分支拉满：

| factId | 内容 | 谁 · confidence · sourceHow |
|---|---|---|
| F1 | 失声是"标音台事故" | 大众 · `misinformed` · `told`；岑野初期 · `misinformed` |
| F2 | 失声的人其实是**被过户走了** | 岑野 · `suspect` · `inferred`；得劲 · `suspect` · `discovered` |
| F3 | 标音台在**采集**而非消灭声音 | 蔺守一 · `certain` · `witnessed`；佟响 · `suspect` · `told` |
| F4 | 高保真要把人声做成**标准商品（母带分级）** | 席准 · `certain` · `witnessed`；多数人 · `unknown` |
| F5 | 岑野出生于"标准音"实验 | 郗伯 · `certain` · `witnessed`；岑野 · `unknown` |
| F6 | 「卡带」是第一个被过户走的人 | 岑野 · 由 `misinformed` → `certain`（跨卷转变） |

**必造用例（专测 bug）**：
- **误信**：F1 必须是 `misinformed`，不能写成 `certain`（防"全员全知"）；
- **未知**：F5 对岑野必须是 `unknown`（防"主角开天眼"）；
- **串知**：故意让**得劲**在某章"说漏"F4 → 应被限知校验拦下（该实体无 `witnessed/told/inferred` 来源链）；
- **转变可溯**：F6 的 `misinformed → certain` 要能查到"哪一章、因为什么"改的信。

线索道具（`ClueTab`）：黑信封（F1）、半卷录音带（F3）、旧钥匙（F2/F6）、一张写满名字的"母带清单"（F4）——**每件线索带 `activeFromChapter/activeToChapter`**，测生命周期。

## 十二、反 AI 味与年轻人向的写法约束（写进题材 `styleProfile` + 约束词）

1. **禁止段尾俏皮话**：紧张场景笑点配额 **= 0**（上一本最大翻车点）。
2. **禁止抽象升华**：章末落点是**具体物件/动作**（冷钩子），不是"命运的齿轮"。
3. **意象台账**：每个高频意象（雨、霉味、算盘声）全书**只准出现一次**，跨章语义查重。
4. **配角先有自己的账**：每个配角在被主角需要之前，必须有**自己的目标与交易**。
5. **代价前置**：每次爽点当口必须兑现代价，"无代价的爽是廉价的"。
6. **喜剧场景自适应**：笑点密度服从场景，不服从"每章≥3处"的机械指标。
7. **年轻人的玩意，落点在"事"不在"梗"**：不堆网络热词（还会被检测器拦），落 **外卖/直播/闲鱼/剧本杀/考研/搭子/谷子/整顿职场** 这类**当代生活肌理**——是背景土壤，不是口播段子。

## 十三、自评（我自己给这个方案挑刺）

**它最值钱的地方：**
- **系统即骨头**：13 个待测系统全部是剧情主规则，用例长在剧情上，不用硬编、藏不住 bug——这是对系统最狠的压测方式。
- **方言差异化够硬**：把地域文化做进战斗系统本体，比"带点口音"高一档，且直接吃满 `data/dialects` 方言库。
- **主角金手指是负数**：有记忆点，且天然克制"开挂"（禁忌 2），把爽点锁死在"规则漏洞"上——正好复用上一本被验证有效的东西。

**可能会翻车的地方（我担心的）：**
1. **概念密度高，前 3 章容易变设定说明书**。上一本"设定 A 级、工艺 C 级"的病，这本题材更危险。**对策**：前 3 章只许用"一件物、一次过户"教规则，**禁止开局讲体系**；规则三问每条配 ≥3 个日常场景。
2. **方言写不好就是刻板印象 + 四不像**，还可能与检测器打架。**对策**：只做语感锚点（句尾/称呼/用词表）+ 系统注入，禁止谐音字幕；加"口音一致性"抽检。
3. **压测会把真 bug 顶出来**（带出门禁、限知串知、编年史回流首当其冲）。**对策**：先上软门禁 + 告警 + `materialDebt` 显式债务，别让写作被卡死——**这是压测目的，不是事故**。
4. **容易写成"设定猎奇"**，缺人味。**对策**：每卷必须有**情感账**（师徒瞒骗、认同流失、代价结算），压住设定。

**一句话自评：**
> 作为**压测载体**，这东西是称职的——它逼每个系统在剧情里**必须开口回答**；
> 作为**小说**，创意分我给 **8/10**，执行风险 **7/10**（风险全在"把概念讲成人话"这一步）。
> 它成不成功不看设定多花哨，看**第一件过户的小事讲不讲得住**——那件小事立住了，后面全是顺水推舟。
