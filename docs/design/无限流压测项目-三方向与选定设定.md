# 无限流压测项目：三方向对比 + 选定设定方案

> **本文取代** `压测项目-调包（腔调方言·实体中心全量压测）.md`（那版是"测试夹具"，不是小说，已废）。
> **原则（本文纲）**：**框架优先**——不是"为了测系统去编剧情"，而是**先立一个能扛四五百万字的好框架**，
> 再确认这个框架**天然用得上**实体中心的那些机制。用不上，说明框架不完整；测得崩，说明框架搭错了。
> **状态**：三方向已列，选定【方向 A】，设定待确认 → 确认即开工。

## 一、为什么"测试服务框架"而不是反过来

四五百万字 = 1500–2500 章。能撑住的框架必须同时具备五样东西：

| 长篇刚需 | 没有会怎样 | 对应实体中心机制（=被顺带测的） |
|---|---|---|
| 可无限扩展的舞台 | 写到十万字没得写 | 世界域 / 副本层级 |
| 有代价、有稀缺的资源循环 | 装备数值通胀，爽感归零 | 装备 / 归属绑定 / 带出条件 |
| 一条贯穿全书的信息主线 | 单元剧疲软、弃书 | 限知 / 线索 / 追溯定位 |
| 能长期跟踪的人物群像 | 配角工具人、记不住 | 角色 / 编年史 / 仆人 / 方言地域 |
| 起伏的节奏曲线 | 高开低走、烂尾 | 篇章节奏 / 伏笔可行性 |

**结论**：这些机制**本来就是长篇的骨头**。所谓"测试"，测的就是"这套骨头能不能撑起5M字"。所以不存在"为了测试而测试"——**测不过的就是框架缺陷，必须改框架，不是改测试。**

## 二、三个方向（都是无限流家族，都能测全，差异在"怎么撑5M字"）

### 方向 A ·《勘定》——都市异化副本 + 文明切片长线
- **钩子**：城市里会"长出"一些房间/街区，把某段生活或某个地方的规矩封成铁律；主角是民间"勘定师"，唯一的本事是**能把这些地方的规矩读明白，并把东西"合法带出来"**。
- **金手指**：**过界**（读出规则 → 补全渠道 → 带出）。别人进得去出不来，他带得出来。
- **长线**：这些"界"是一个正在褪色的平行文明的碎片；主角集齐"规则残页"→ 揭文明真相 → 终局抉择。
- **撑5M**：主位面（当代都市）做锚点，副本题材**不设限**（都市/民俗/时代/科幻都能装），层级无限升。
- **受众**：男频 18–28 为主，都市×悬疑×规则怪谈交叉，免费站也吃。
- **风险**：规则怪谈已卷；靠"地域民俗副本 + 主角人设"差异化。

### 方向 B ·《带一件就走》——万界搬运 + 交易长线
- **钩子**：主角能穿万界，但**每次只能带一件东西走**，且被各界的"带出规矩"卡死——他成了万界之间最抢手的搬运工。
- **金手指**：**跨界携带**（带出/归属，直接是核心机制）。
- **长线**：万界在互相吞噬，他要建"通道网"，最后成为规则的解释者。
- **撑5M**：每个世界=一单生意=一个单元；主线是"通道网"扩张。
- **受众**：男频 18–30，诸天爽文大盘。
- **风险**：诸天流套路化，容易写成"逛超市"，对人物和情感账要求极高。

### 方向 C ·《次位面·锈》——高武双界（复用现有插件）
- **钩子**：主位面是高武都市，飞天战力进了"次位面"被打回原形，只有规则能救命；主角是主位面废柴、次位面规则黑客。
- **金手指**：**次位面读规则**。
- **长线**：主位面宗门/财阀斗争 + 次位面升级 + "锈蚀"暗线。
- **撑5M**：与系统现有 `high-martial-crossplane` 结构同源，改造最小。
- **受众**：15–30 男频，高武×无限流。
- **风险**：与现有《主位面高武》项目**同源，重复度高**；高武+副本也卷。

### 三方向速览

| 维度 | A 勘定 | B 搬运 | C 锈 |
|---|---|---|---|
| 主位面锚点强度 | **强** | 弱 | 强 |
| 副本题材自由度（撑5M关键） | **最高** | 高 | 中 |
| 差异化（不与现有项目撞） | **高** | 中 | **低** |
| 年轻读者代入 | **强** | 中 | 中 |
| 测试点覆盖 | 全 | 全 | 全 |
| 框架风险 | 卷 | **套路化** | 同源重复 |

## 三、选定：方向 A《勘定》

**为什么是 A**：主位面锚点最强（保住长线情感与势力）+ 副本题材不设限（保住5M的胃口不腻）+ 地域民俗副本给了**方言地域测试点一个天然的家**（不是硬塞）+ 不与现有项目撞。

### 3.1 世界观（一页纸）

- **主位面**：当代都市（近未来三五年）。超凡不公开，藏在"民间行当"里。
- **界（副本）**：某些地点会"结"成独立的规矩空间——进去就得守它的规矩，规矩写在那地方本身里，不写在纸上。
  - 界的来源：**一个正在褪色的平行文明「旧界」的碎片**。每个界=旧界某段生活的残影。
- **带出**：界里的东西（器物/资料/甚至活物）**默认带不出来**；能不能带、要什么凭据，由**界的出口规矩**决定。→ 这就是主角的饭碗，也是全书资源循环。
- **追溯**：每次跨界都留痕；没留痕的跨界=走私="串台"，会被行当追杀。→ 追溯定位机制的剧情化。

### 3.2 力量体系：勘（四阶，带特效与代价）

| 阶 | 名 | 能力 | 代价 |
|---|---|---|---|
| 一阶 | **识规** | 看见一个界明面上的规矩 | 出界后短暂失语 |
| 二阶 | **勘误** | 找到规矩的漏洞/边界条件 | 损耗"记性"（忘事） |
| 三阶 | **改规** | 改写一条规矩（限一次、限本界） | 折寿/折运，且改动的账挂在自己身上 |
| 四阶 | **立规** | 自己定一条规矩（禁术） | 立规者被这条规矩**终身约束** |

> 四阶对应 5M 字的升级曲线；每阶特效不同 → 天然命中"功夫阶段寻址"测试。

### 3.3 界的层级 × 带出政策（六档全覆盖）

| 层级 | 示例界 | 出口规矩 | carryOutPolicy | 渠道标签 |
|---|---|---|---|---|
| 浅界 | 拆迁楼 / 老录像厅 | 认人认信物 | `medium` | 退租凭证 |
| 浅界 | 夜市摊 / 相亲角 | 交易即绑定 | `plot` | 收摊令 |
| 中界 | 绿皮车厢 / 长途车站 | 认票根权限 | `permission` | 补票章 |
| 中界 | 老考场 / 体检中心 | 认一次性凭证 | `item` | 准入码 |
| 深界 | 方言围屋 / 老村 | 原生物可带 | `native` | 围屋水牌 |
| 深界 | 静音仓 / 直播间 | 只进不出 | `locked` | （无→告警） |
| 源界 | 回音壁 / 旧界中枢 | 复合授权 | `plot+permission` | 合唱歌单 |

> 界的题材**不限于都市生活**，还可装历史/民俗/科幻——这是它撑得住5M的核心。

### 3.4 主位面势力（长线冲突源）

| **清界集团**（资本） | 想把界变成商品/景区 | 主要反派 |
| **守界人**（各地民俗守护者） | 守着老规矩不让动 | 亦敌亦友 |

### 3.6 主线与限知分层（贯穿5M字的信息线）

核心谜：**旧界为什么褪色？主角为什么"记得"自己不属于主位面？**

| 层 | 事实 | 谁·确信度·来源 | 揭示卷 |
|---|---|---|---|

| F2 | 界是**旧界碎片**，不是自然现象 | 岑野·`suspect`·inferred | 卷一末 |
| F3 | 旧界在主动"挑选人"带走 | 蓝阿妹·`certain`·witnessed；多数·`unknown` | 卷二 |
| F4 | 清界集团在**批量搬运旧界人口**当商品 | 席准·`certain`·witnessed | 卷三 |
| F5 | 岑野那夜**在旧界被"登记"过** | 师父·`certain`·witnessed；岑野·`unknown` | 卷四 |
| F6 | 旧界褪色是**主角那一夜造成的** | 岑野·`misinformed`→`certain` | 卷五–六 |

> 6 条 fact、四种确信度、四种来源、跨卷转变——**限知三维度的所有分支都被剧情用到**，不是为测而测。

### 3.7 五百万字框架（卷结构 · 升级曲线 · 循环）

**主循环（每本/每单元）**：接界务 → 进界摸规矩 → 撞上出口/权限卡点 → 勘误找漏洞 → 带出/封界 → 兑现代价 → 主线推一格。

| 卷 | 名 | 章数 | 界层级 | 主角阶 | 主线推进 | 主味 |
|---|---|---|---|---|---|---|
| 一 | 《落脚》 | 1–250 | 浅界 | 一阶·识规 | F1→F2 | 爽+悬 |
| 二 | 《守界》 | 251–600 | 浅/中界 | 二阶·勘误 | F3 | 燃+暖 |
| 三 | 《越阶》 | 601–1050 | 中/深界 | 二阶→三阶 | F4 | 谋+震撼 |
| 四 | 《溯源》 | 1051–1600 | 深/源界 | 三阶·改规 | F5 | 悬+悲 |
| 五 | 《裂界》 | 1601–2150 | 位面级 | 三阶→四阶 | F6 半 | 燃+怕 |
| 六 | 《立规》 | 2151–2500 | 终局 | 四阶·立规 | F6 全 | 悲+燃 |

> 每卷副本题材换一批（都市→民俗→时代→科幻→位面），**保证5M字不腻**；主位面势力随卷升级，情感锚点（弟弟/老家/师父）不断线。

### 3.8 篇章节奏与情绪配方

- **主情绪**：爽（智性爽：看普通人用规则漏洞赢）+ 悬（旧界真相）。
- **配方**：智斗40% / 悬25% / 燃15% / 暖10% / 悲10%。紧张场景笑点=0。
- **节奏**：每2章小反转；每单元（5–15章）一次完整"带出/封界"；每卷一次"大震撼"（限知升级）。
- **开篇铁律**：前1000字必须同时有**冲突 + 信息差 + 反常**。
- **卷末不跳时**，结局三件套（代价/死谁/怎么上位）写清。

### 3.9 反AI味约束（沿用系统 sop/12）

1. 禁段尾俏皮话（紧张场景笑点=0）；2. 禁抽象升华（章末落点是具体物件/动作）；3. 意象台账（高频意象全书只准一次）；4. 配角先有自己的账；5. 代价前置；6. 喜剧场景自适应；7. **地域性只在"人怎么说话、怎么过日子"上体现，禁止谐音字幕与刻板印象**。

## 四、测试点映射（每个问题点 → 框架里"本来就在用"的位置）

> **判据**：能指出"它在哪一卷、哪个界、哪个角色身上**非用不可**"，才算测点合格；指不出，就是框架缺了它。

| 待测系统 | 框架里的天然位置 | 用例 | 断言 / 预期 |
|---|---|---|---|
| 角色 | 9 人勘定队 + 反派 | 初始化产出四件套/魅力/出场设计 | 无空壳角色卡 |
| 编年史（八维） | 跨卷人物成长（2500章） | 第 5/300/1100 章跑三档 | daily/psychology/highlights/relations 有数据 |
| 编年史·回流 | 名言/高光回流 `quoteLibrary`/`highlightScenes` | 去重合并、可回溯章节 | 回流触发、无重复 |
| 限知（三维度） | F1–F6 信息线 | 每卷各验一次确信度/来源链 | 无"全员全知"、无"主角开天眼" |
| 限知·串知 | 冉得说漏 F4 | 该实体无来源链 → 拦下定位 | 有串知检测 |
| 装备 | 界产器物（带阶段） | 渔鼓/取件码等 stages | 按阶载入、摘要存地址 |
| 功夫 | 勘·四阶 | 一阶→四阶，代价兑现 | 每阶独立特效 |
| 线索 | 规则残页 | `activeFrom/To` 生命周期 | 过期不注入 |
| 仆人 | 契约仆（钩子/转述） | `masterId` + 域归属 | 主人≠渠道，带出按界规 |
| 世界域 | 主位面 + 浅/中/深/源界 | 层界面板/契约 | 每界一行契约、归属数正确 |
| 篇章节奏 | 六卷 + 单元剧 | 大纲节奏校验 | 每卷钩子密度达标 |
| 归属绑定 | 界内器物/NPC/仆 的 `scopeWorldId/locationSlot/bindMedium` | 实体中心可查 | 字段不丢、detailText 注入 |
| 带出条件（六档） | 每界的出口规矩 | 白拿→拦；补凭据→放；native→放 | `carryOutGate` 六策略各命中一次 |
| 渠道标签 | 每次出界 | `channel` 非空 | 缺渠道→告警不静默 |
| 追溯定位 | 跨界留痕 | `traceLog` 带 channel/medium/action | 类型不漏、可回放 |
| 串台检测 | 界A的人出现在界B | 无渠道=阻断/告警 | 硬阻断接 `materialGate` |
| 方言地域风格 | 9 人跨地域 + 民俗界 | 跨卷口音一致 | 无漂移、无刻板音译 |
| 章节门槛 | 跳章/断档 | 前章未归档不写后章 | 阻塞+补跑+告警，不静默 |
