### E4 · 覆盖率账本诚实化（G4）
- **根因**：`collectCoverageFrom` 只有 80 个文件的**白名单**，而 server 有 935 个 JS → "语句覆盖 91%" 只描述约 8.5% 的后端；且白名单**恰好剔除了 F1–F11 全部肇事子系统**（chapterAuditor / validationEngine / technique* / worldScope / craft* / blindJudge / holdout）。
- **改**：
  1. 口径改为**全量 `server/**/*.js`**（排除 tests/scripts/docs/node_modules），覆盖文件数 80 → **600**；
  2. 阈值按**实测真实水位**重设并注明（global 42/31/39/46；`server/config/` funcs 90→86；`server/shared/` stmts 90→89、funcs 95→85——后者是"口径放宽后目录聚合值下降"，非放水，见第 3 条棘轮兜底）；

  4. 基线按"历史最优"合并（`mergeBaseline`），避免把一次抖动固化成新地板。
- **容差为什么不是 0**（实测得出，非拍脑袋）：项目 jest 多 worker 并行，个别文件覆盖率有 run-to-run 抖动。三轮实测（4079 例全绿 × 3）只有 1 个文件波动：`server/shared/debugPgWriter.js` 分支 ±10pp（它只有 10 个分支，丢 1 个即 10pp）。故容差 = **5pp + 1 个单元的百分点**（`100/单元总数`），聚合指标容差 0.5pp。
- **顺带修掉的"环境决定覆盖率"**：`server/db/jsonStoreHelpers.js` 的覆盖率原本取决于 `data/.jsonstore.pid` 残留（跨 worker 竞争）→ 新增 `tests/unit/jsonStoreProcessLock.test.js`（mock `process.kill` 显式构造"存活/已退出"两种情形），该文件覆盖率由抖动变为**确定性 66.67%**。
- **验收**：`coverage:check` exit 0；棘轮对三次真实运行均 ✅ 无退化；反向验证（把基线抬高 7.59pp 立刻报错）；`test:unit` 281 套件 / 4080 例全绿。

### E6a · 依赖装不全（uuid/multer）
- 根因：`uuid`/`multer` 只声明在 `server/package.json`（+ `server/package-lock.json`），
  而所有 CI job 只在**根目录** `npm install` → 干净检出加载后端模块必失败
  （本机能跑只是因为磁盘上有手工装的 `server/node_modules`，且它被 gitignore）。
- 修：`backend-test` / `backend-integration` / `backend-e2e-material` / `gates` / `e2e-smoke` 五个 job
  增加 `working-directory: server` 的 `npm ci`。
- 验收：e2e-smoke ✅、gates 的模块加载段全 ✅。

### E6b · 形状基线跨平台（Windows 反斜杠 vs Linux 斜杠）
- 根因：`scripts/materialShapeBaseline.json` 的键由本机 Windows 生成（`server\routes\...`），
  Linux 上 `collectWriteSites` 产出 `/` → 基线查不到 → **26 个文件全被判为"新增写入点"** → 非 Windows 必红。
- 修：键统一 POSIX（`toPosix`）、读入时归一化兼容旧基线、重生成基线；
  `materialShapeGate.test.js` 失败时带出子进程输出（原来只剩 "Command failed"，无法诊断）；
  新增"基线键必须为 POSIX"回归断言；`eslint.config.js` 登记 `dbTest` 测试块别名。
- 验收：backend-test ✅；9 例全绿。

### E6c-1 · checkMemory 环境相关断言
- 根因：`tests/unit/healthDeepRoutes.test.js` 断言 `result.ok === true`，
  而 ok 取决于 `rss > 阈值` → CI runner/并行 worker 的 RSS 超阈值即红。
- 修：改为断言**自洽性**（布尔 + ok=false 必有 warning），指标断言全保留。
- 验收：gates ✅（第 3 跑全链通过）。
