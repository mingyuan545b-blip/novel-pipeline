## 四、本轮新发现（G1–G12，均为门禁/账本层面的样子货）

### G1【P0】GitHub Actions CI 永远不会运行
- `git remote -v` → 无远端；ci.yml 触发 push:[main,master,dev] / pull_request:[main,master]，工作分支为 milestone/M5-pipeline，不在其中。
- 复现：`git remote -v && git branch --show-current`
- 影响：lint / jest / vitest / doc-freshness / npm audit / gitleaks 全部 0 次执行；ci.yml 目前是装饰品。

### G2【P0】ci:check（30 道自研门禁）不在任何自动化里，且当前为红

- 影响：ci:check 现状即失败，而它只在人手动敲时才跑 → 「门禁全绿」是不可达状态。

### G3【P0】verifyApiContract 的 37 条断裂 100% 是误报（门禁自己坏了）
- 根因：scripts/apiContractRoutePrefixes.js 前缀表陈旧/错误：
