# 2026-10-17 工艺素材门禁重建（M1 止血）— 根因修复，非补丁

> 指令（用户）：读参考书《全球死考》→ 让 agent 学真人写法（拆解可组合，不照抄）→ 定素材质量标准 →
> 严格验收 + 防旧数据污染 + 允许破坏性重构 → **授权**破坏性重构、引入留出集（任意一本）、开始改造。
> 定位：M1「止血」——把已写成文字的工艺标准，真正变成**写入路径上的门禁**。

## 一、取证（只读，实测）

### 1.1 现象：`craftQualitySpec` 明令禁止的反模式，实实在在躺在库里
- Entity `quoteLibrary` 抽样：`quote="面对新人鲁莽行动：“脑子是用来算账的…”"`（**处境混入 quote**）、
  `speaker=""`、`chapter=0`、`why="记忆点：强调理性至上"`（**标签式 why**，不是记忆点）。
- Entity `highlightScenes` 抽样：`what="摇头否定…并给出基于0.5秒逻辑空窗期的精密方案。"`（**剧情摘要**）、
  `why="因为他信奉…所以宁可…也不…"`（因果解释，非记忆点）、部分条目 `cost` 为空。

### 1.2 根因（三层，全部实证）
- **R1 校验器只查长度与少量禁词**，不查"结构性反模式"：
  - `validateQuotes`：不查 quote 是否混入处境前缀、scene 是否空壳词、why 是否标签式、quote 是否回查原文。
  - `validateHighlights`：`cost` 归一化后**不校验**（高光四问"有代价"形同虚设）；`what` 无"剧情摘要"判定。
- **R2 存在绕过校验的写入路径**（关键）：
  - `pipeline/characterStateExtractor.extractQuoteLibrary()`（设计期解析【金句库】）→
    `entityProjection.buildCharacterEntityPatch()` → `outlineEntitySync` / `materialItemProcessor` /
    `steps/materialCharacterProcessor` → `entityCenter.updateEntity()`，**全程无 craft 校验**。
  - `steps/materialCharacterProcessor.processTraitNotes()` 直接写 `catchphrases: [charUpdate.catchphraseNote]`（裸字符串）→ 同上，无校验。
- **R3 丢弃即静默**：`entityCraftReflow` / `characterChronicle` 的 catch 只 `logger.warn`，无指标、不阻断。

### 1.3 唯一写入点定位
`entityCenter/entityCRUD.updateEntity`（被 merge 路径 `mergeExistingEntity` 复用）+ `getOrCreateEntity` 新建路径
= 所有实体写入的**唯一汇合点**。在此加门禁即可覆盖全部路径（设计期/运行期/修复路由）。

## 四、结果（实测）

### 4.1 存量差距（首次量化）— `node scripts/audit-craft-quality.js`
```

        7d3e3e66=31  35ae6660=6 8bc180d6=11  ff24c57a=4  b2154143=6  e0b36a30=6
样例：quote 混入处境前缀 / scene 空壳词（处境·通用场景）/ why 标签式（记忆点：…）
```

→ **66% 的角色实体带违规工艺字段**。这就是"素材质量离 95% 的差距"的可测基线。

### 4.2 门禁生效
- `craftWriteGate` 在 `entityCRUD.getOrCreateEntity` / `updateEntity`（唯一写入汇合点）过滤不合格工艺字段，
  **丢弃并告警**（非静默）。覆盖：设计期解析 / 素材管理员增量 / 编年史回流 / 修复路由。
- 端到端接线有测试保障：`tests/unit/entityWriteGateWiring.test.js`（不合格不落库 / 合格正常落库）。

### 4.3 测试与静态检查
- `tests/unit`：**269 套件 / 4054 例 全绿**（M1 新增 3 个测试文件 + 7 条负例）。
- `npx eslint server/services` `--max-warnings=0` 通过；改动文件均 ≤200 行。
- 已知 flaky（与本改无关）：`pipelineMetricsPercentile.test.js` 在并行满载时偶发失败，单跑通过。

### 4.4 源头对齐（"既查也写"）
- `craftDesigner` 提示词补：scene 禁空壳词、quote 禁混处境、what 禁事件复述；
- `craftQualitySpec.buildCraftGuidance()` 补共通硬性（所有消费端同步可见）。
