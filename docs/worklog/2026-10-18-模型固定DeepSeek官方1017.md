# 2026-10-18 模型固定：DeepSeek 官方 V4.1 Flash · 1017

## 结论

默认模型已从「百炼 TokenPlan · Qwen3.8 Max」切换为
**DeepSeek 官方 API · `deepseek-flash`**（界面上显示为
`DeepSeek官方 · DeepSeek V4.1 Flash · 1017`，1,048,576 上下文）。

## 为什么 Qwen3.8 在会话内“不能选”

1. `start-claude.ps1` 用 `--setting-sources project,local` 启动，**排除了 user settings**；
   因此 `~/.claude/settings.json` 里的 `modelPicker.options` 不会被加载。
2. 启动器只设置了 `ANTHROPIC_MODEL` 等模型槽位，**没有设置**
   `ANTHROPIC_CUSTOM_MODEL_OPTION` / `_NAME` / `_DESCRIPTION`。
   Claude Code 因此只看到内置模型列表，自定义模型在会话内不可选。
3. 百炼目录本身是正常的：`qwen3.8-max` 仍在
   `https://token-plan.cn-beijing.maas.aliyuncs.com/compatible-mode/v1/models` 返回列表中；
   问题在启动器注入，不是模型下线。

## 怎么切回 / 切换

```cmd
:: 默认（官方 DeepSeek 1017）
启动-Claude.cmd
start-claude.cmd

:: 百炼 DS（TokenPlan）
启动-Claude.cmd -Provider bailian -Model deepseek-v4.1-flash

:: 百炼 Qwen
启动-Claude.cmd -Provider bailian -Model qwen3.8-max
```

**重要**：会话内的模型选择器只能选同一 provider 下的模型。跨 provider
（官方 DS ↔ 百炼）必须用不同的启动参数/快捷方式，因为 baseUrl 和 API Key
在启动时已固定。
