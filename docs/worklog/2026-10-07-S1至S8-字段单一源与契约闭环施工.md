- 改动：
  - `chapterStatus.js` 升级为单一真相源：IN_PROGRESS 补入两 reviewed 态、INITIAL 补 draft；
    新增 `REVIEWED_STATUSES / STATUS_LABELS / STATUS_COLORS / STATUS_ORDER / VALID_TRANSITIONS` 与
    `isReviewedStatus`；`validateStatusConsistency` 增校验"迁移表引用 ⊆ ALL_STATUSES / 状态都有标签"。
  - `chapterStateMachine.js` 改为薄封装（词汇表/迁移表来自 chapterStatus），迁移表补 reviewed。
  - `orchestratorStepHandlers` 三处重复 statusMap 收敛为 `markReviewPassed()`（用 STATUS_VALUES）。
  - `validators.js` 章节状态白名单改用 ALL_STATUSES。
  - 新增闸门 `scripts/audit-vocabulary-consistency.js`（check#4：statusMap 值 / 章节流程 `.status` 赋值 /
    迁移表 / 前端生成常量同步）并接入 `ci:check`。
  - 前端 `chapterStatusConstants.js` 改由 `scripts/generateChapterStatusConstants.js` 生成（--check 校验漂移）。
