## 五、过程中发现并修掉的真实缺陷（重要）

### 5.1 DataContext 缓存从不失效 → "改了没用"

`getDataContext(projectId)` 返回**进程内单例**，`_cached()` **无 TTL**；
而 `PUT /api/projects/:id`、`PUT /api/materials/:id`、`PUT /:id/targets`、`PUT /:id/style-guidance`
**全都没有失效缓存**（`memory.invalidateCache` 只清分层记忆，不清 DataContext）。

**实测复现**（脚本已跑，证据如下）：
```
1) 缓存后读到方言: ""
2) 直接改库、不失效缓存 → 仍读到 ""   ← 缺陷成立
3) resetDataContext 后 → 读到 "东北"   ← 修复有效
```
**修复**：上述 4 个写入口补 `resetDataContext(projectId)`（复用既有导出，不新造机制）。
这直接决定用户诉求"编辑保存后能被后续 agent 同步读到"能否成立。

### 5.2 主题变量名错配（全站视觉失效）

运行时实测：`--accent-primary`、`--card-bg`、`--input-bg` **全部未定义**
（真实变量是 `--text-accent` / `--bg-card` / `--bg-input`）。
后果：`var(--accent-primary)` 解析为空 → `background: linear-gradient(...)` 整条声明失效
→ **运行看板进度条渲染为一条空栏**（实测 `backgroundImage: "none"`）。

**修复**：本轮涉及的 5 个文件共 65 处变量名纠正
（新增 3 个 + 既有 `TemplatesPanel.jsx` / `MaterialTreePanel.module.css`）；
进度条改用 `var(--gradient-accent)` 以随皮肤变化。

## 八、用户反馈修复：角色设定表单崩溃（2026-10-01 追加）

**用户报告**：全书设定 → 角色设定"数据格式不匹配，可能是后端返回了对象而非字符串"。

**实际根因（与猜测不同，已用浏览器复现）**：
```
TypeError: Cannot read properties of undefined (reading 'map') at PresetSelect
```
方言/语体清单挂在 `useStoryBibleState`（`st.dialects`/`st.speechStyles`），
但 `CharacterSettingPanel` 取的是 `cs.dialects`（`useCharacterSettings` 的返回值，**根本没这两个字段**）
→ `options` 为 `undefined` → 点选任一角色即 `.map` 崩溃 → 被 ErrorBoundary 接住，角色编辑区整块不可用。

**为什么上一轮没测出来**：`uiBugCheck` 只"访问页面"，而该表单**必须点选角色才渲染**，
所以巡检报 0 问题。**这是验证方法的盲区，不是偶发。**

**修复**：
1. `StoryBiblePage` 显式传入 `dialects` / `speechStyles`；`PresetSelect` 对 `options` 加 `|| []` 兜底。
2. **顺带把用户的猜测也一并防住**（该风险真实存在）：
   新增 `asText(v)` / `asIntensity(v)`——受控 input 的 value 若是对象，React 会渲染成 `[object Object]`；
   而 `parentPlane`/`parentFaction` 是引用型字段（写入路径经 `normalizeMaterial`，可能非字符串），
   强度字段还受后端 `isIn(['light','medium','heavy'])` 约束。
   播种/渲染/项目表单全部改走 `asText`，强度走 `asIntensity`（非法值回落 medium，避免保存 400）。
3. **补齐验证方法**：`scripts/uiBugCheck.js` 新增**交互探针**（`INTERACTIONS` 表）：
   访问后自动点选第一个可点元素再做检查。`/story-bible` 点角色、`/library` 点来源卡。

**验证（浏览器实测，非仅接口）**：
| 项 | 结果 |
|---|---|
| 点选角色后表单渲染 | 8 个字段全部正常（方言/强度/语体/强度/位面/势力/简介/性格背景） |
| 方言候选下拉 | **21 项**；语体 **14 项**（证明 props 已接通） |
| 保存链路 | 设「东北」→ 保存 → API 读回 `dialectRegion="东北"` ✓ |
| 页面 `[object Object]` | 无 |
| console 报错 | 无 |
| 交互探针巡检 | `/story-bible` 点击后 **0 问题** |
| 数据还原 | 已还原（并修正了我自己还原脚本中"用旧对象覆盖"的二次写入错误） |
| 单测 | `storyBibleConstants.test.js` 11 例（asText 绝不产出 `[object Object]`、asIntensity 回落） |
