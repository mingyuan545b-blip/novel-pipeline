## 三、发现的 bug / 问题

1. **【已修复·硬 bug】分支题材 writer 提示词不完整 → PROMPT_INCOMPLETE 硬停**
   - 现象：`genre-foundation(题材铁律)` 槽位解析为 null，writer 直接抛错，三章全停。
   - 根因：`agentPromptAssembler._fetchSharedData` 用 `detectGenre(styleProfile)` 取题材，**丢失分支上下文**（分支 `styleProfileOverrides.key` 不是题材 id，如 `kanding-rules-thriller`）→ 基础题材 `genre-foundation` 为空 → 硬停。**影响所有带自定义 styleProfile.key 的分支**。
   - 修复：优先 `resolveGenreFromProject(project)`（含 subGenre+branchKey），失败回退 detectGenre。`agentPrompts.test.js` 26/26 通过。
2. **【发现】单次素材生成有量上限**：一次要求 11 角色 + 全设定 → JSON 截断 → 解析失败 0 产出；拆 3~4 批即成功。
3. **【发现】非角色素材 `saveMaterial` 无 upsert**：同名唯一约束 `idx_materials_project_type_name` 触发 → **整批回滚**（批次C 0 产出）。
4. **【发现】门槛拦下后一次性 `/full` 任务不自动续跑**：需外部重触发；infinite 批量循环不受影响，但单章 API 调用方要处理。
5. **【发现·待排查】编年史/世界域归属/穿越留痕 三章后仍为 0**：`character-chronicle`=0、`world-scopes`=0、`cross-world-traces`=0。提取链在 T0 未产出，需定位（是否 T2+ 才触发 / 提取器未接 / 配置缺失）。
