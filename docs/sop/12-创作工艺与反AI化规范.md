## 零、一句话结论

本书的**设定是A级，工艺是C级**。
- 设定（"以账治世"+《苍生簿》）新鲜、自洽度初期高，是能出圈的概念。
- 但工艺层（人物塑造、章节衔接、情绪节奏、结尾收束）出现了**系统性的AI写作病**，导致"高开低走、烂尾嫌疑"。
- **根因不在"文笔"，而在三件事**：①素材库里**角色卡是空的**；②设定被写成了**规则说明书**；③"喜剧配额"被当成了**均匀撒糖指标**。
- 本文的核心主张：**好小说 = 读者承诺 × 情绪配方 × 因果闭环 × 具体质感**，四项都必须在"开写前"就配置好，而不是靠写作时的措辞润色去救。

## 一、老书虫视角诊断：这本书到底怎么样

### 1.1 先给分（十年网文读者视角，非编辑视角）

| 维度 | 评分 | 说明 |
|---|---|---|
| 概念/设定新颖度 | 8.5 | "以账治世"把江湖权力换成"账权"，冷、狠、少见 |
| 开篇吸引力（前3章） | 8.0 | 销籍、黑信封、算盘声登场，钩子密度够 |
| 人设辨识度 | 6.0 | 主角吐槽役立住了，但**配角全是功能键** |
| 逻辑自洽 | 5.5 | 中后期"存在抹除"与"假死长期有效"打架 |
| 章节衔接 | 4.5 | 多处道具/场景凭空出现或凭空消失 |
| 情绪节奏 | 5.5 | 张力刚起来就被插科打诨打断 |
| 文字质感 | 5.5 | 意象复用严重（腐臭/霉味/算盘声），AI味明显 |
| 结尾收束 | 4.0 | "一年后"跳时，革命代价全无，典型烂尾结构 |
| **综合** | **6.0** | **可追、可惜、差点能封神** |

### 1.2 先说优点（不夸不行，不然改不对方向）

1. **概念狠**：把"钱/债/账"当江湖的权力本体——"账平了，人心才能稳""死人是最安全的""把人命量化成债务"。这类**把抽象制度变成世界规则**的设定，比"多一个境界"高级得多。
2. **主角方法论对**：沈砚赢，靠的是**信息差 + 规则漏洞**，不是拳头。第一章用"顺通号沉船案"吓退赵四，是全书最漂亮的智斗示范——**用对方的恐惧当武器**。
3. **开篇画面准**：雨、铁皮棚、断毛笔杆、彼岸花火漆印。前2章的"冷硬质感"是全书巅峰。
4. **单章钩子意识强**：每章结尾都留东西，作者（管线）知道要"勾下一章"。

### 1.3 七个致命问题（附原文证据 + 老书虫内心OS）

#### 问题1：主角"降智"——人设与行为自相矛盾
- **证据**：第7章刚确立"死人是最安全的，没人会追杀一个已结账的死鬼"；第9章沈砚却**主动现身人流量最大的茶肆**、当众散布谣言挑拨两派。
- **老书虫OS**：他前面惜命惜到钻排污沟，现在为了推剧情跑去送人头？**人设崩了**。
- **本质**：不是作者不会写聪明人，是**大纲需要他此刻出现在那里**，于是强行让他"忘了自己是逃犯"。这叫**剧情驱动角色**，不是**角色驱动剧情**。
- **规避**：任何"角色做反常事"的桥段，必须给出**代价计算**（他为什么别无选择）或**风险对冲**（伪装/替身/盲区/退路）。写不出对冲，就改剧情。

#### 问题2：章节衔接断裂——道具、场景、威胁凭空出现/消失
- **证据A**：第2章拿到的是"黑纸片"，第3章手里突然攥着"烫手的铜钱"，中间无转化描写。
- **证据B（更严重）**：第4章白主簿用"活账之首0001/户籍彻底注销"生死胁迫沈砚；第5章见柳三娘时，**这份生死威胁像没发生过**，主角毫无心理负担。
- **证据C**：第17-19章，从"地下室对峙柳三娘"→"钟楼密室白主簿"→"地道"，场景三连跳，无转场。
- **老书虫OS**：上一章命悬一线，这一章在谈三百两茶水费？**这是两本书记混了吧**。
- **本质**：管线是**逐章生成**的，上一章的"高压尾巴"没有被强制传递到下一章的开头。只保证"素材传递了"，没保证"**情绪与因果传递了**"。
- **规避**：见 §三 Stage5「章首三连」（承接场景/承接情绪/承接悬念）。

#### 问题3：意象复用——同一套形容词全书循环
- **证据**：气味描写反复使用"陈年/腐烂/酸臭/霉"（第1、3、8、9、10章）；算盘声**逐字复用**两次（第3章、第4章都是"算盘珠子碰撞…密集得像一场暴雨前的蝉鸣"）。
- **老书虫OS**：作者是不是只有一套嗅觉词库？看到第三次我已经跳过环境描写了。
- **本质**：AI擅长"复用已成功过的句子"。**第一次惊艳的比喻，第二次就是廉价**。
- **规避**：建立**意象台账**（每个高频意象只见一次），见 §六 6.3。

#### 问题4：配角工具人——出场即高光，退场即遗忘
- **证据**：顾长风第12章登场给线索，13-15章人间蒸发，第16章一句"他已被绑架"；陈默从"要毁掉系统的人"退化成"透明化90%的符号"。
- **更硬的证据**：`tmp_ent.json` 里所有角色卡的 `appearance/background/motivation` **全为空**，只有沈砚有一个被截断的 `fateArc`。
- **老书虫OS**：这些NPC没有"自己的日子要过"，他们只是在主角需要时才存在。
- **本质**：**不是写手不会写，是素材库里根本没给配角"欲望"**。喂给AI的角色卡是空壳，AI只能输出空壳。
- **规避**：见 §七 角色卡四件套硬门禁。

#### 问题5：设定自相矛盾——"全知系统"与"人为操作"打架
- **证据**：第11章确立"违反体系规则→物理层存在抹除+记忆消失"，但第7章柳三娘能随意帮人"假死销籍"且长期无事；系统的"全知全能"时灵时不灵。
- **老书虫OS**：规则只在需要制造危机时存在，需要主角苟活时就失灵——**这规则是橡皮筋**。
- **本质**：设定被写成"一堆机制条目"（世界观素材30条几乎全是"XX机制/XX体系/XX规则"），但**没有写清"边界条件"和"谁执行、执行成本多大"**。
- **规避**：见 §三 Stage1「规则三问」。

#### 问题6：情绪张力泄气——紧张处强行抖机灵
- **证据**（H1开头）："嘴角扯出一个自嘲的弧度。行吧，既然官方都盖章说我是鬼了…说不定还能顺便问问，下面是不是也实行绩效考核制。"类似的还有"适合减肥""差评，必须差评""网上冒充客服""做贼也要讲究可持续发展嘛"（**同一句在1章、2章结尾各出现一次**）。
- **老书虫OS**：我知道你想幽默，但**人命关天的雨夜里讲KPI笑话**，代入感当场碎掉。
- **本质**：这是**最典型的AI味**——不管场景多紧张，都要在段尾接一句"俏皮话"收尾。它不是幽默，是**条件反射式的段尾糖**。
- **规避**：见 §五 反AI化专章 + §三 Stage4「幽默配额制」。

#### 问题7：结尾断崖——"一年后"跳时，代价全无
- **证据**：第19章结尾"这会引发清洗协议！所有人都会死！"，第20章开头"一年。…沈砚坐在对账人太师椅上抱怨投诉信多"。**革命怎么赢的、死了谁、怎么上位的，全无一字**。
- **旁证**：素材库里的伏笔大多标注"埋设于第20-26章"（如0001号活账、忘川水、父亲金徽章），说明**大纲本来还有6+章**，却在第20章被硬切收尾。
- **老书虫OS**：前面生死搏杀，醒来升职加薪，**这是太监式结尾**。
- **本质**：管线"规划超前、执行落后"（设计文档亦已承认此根因），到验证章数就用时间跳跃糊过去。
- **规避**：见 §三 Stage3「卷末不跳时原则」+ 结尾三件套。

## 二、根因分析：为什么AI会写成这样（直连你的管线配置）

> 这一节是最重要的：**改文笔没用，要改的是生产链**。

| 症状 | 表层原因 | 真实根因（管线层） | 对应改造 |
|---|---|---|---|
| 配角工具人 | "写手不会写人" | `tmp_ent.json` 角色卡 appearance/background/motivation **为空**；契约只校验"有深度字段"，不校验"字段非空且具体" | §七 角色卡四件套门禁 |
| 说明文式旁白 | "文笔干" | 世界观素材30条**全是"机制/体系/规则"名词**，喂进prompt就是一堆定义，AI只能转述定义 | §三 Stage1 规则三问 + 素材"体验化" |
| 段尾强行抖机灵 | "作者爱玩梗" | `comedy-mandatory` 硬指标"每章≥3处笑点"被理解成**均匀撒糖**，模型在每段尾找地方交付笑点 | §五 幽默配额制（场景自适应，紧张场景归零） |
| 章节衔接断裂 | "没检查" | `M3章节衔接`只比对"前章末200字 vs 本章头200字"的场景/动作，**不校验被中断的威胁/目标/情绪** | §三 Stage5 章首三连 + 新契约链 |
| 意象复用 | "没查重" | 跨章重复检测只查**逐字**相似度，"陈年腐臭"这种**换词不复用**检测不到 | §六 6.3 意象台账 + 语义查重 |
| 设定矛盾 | "设定乱" | 素材是**平铺的事实条目**，没有"规则-边界-代价-例外"结构，模型自由发挥 | §三 Stage1 规则卡模板 |
| 结尾断崖 | "烂尾" | 规划超前（伏笔埋到26章）但按固定章数（20章）收尾时，**没有"结局可行性评估"门禁** | §三 Stage3 卷末三件套 + 结局门禁 |

**一句话**：本书的问题**几乎全部可以在"开写前"拦掉**，剩下的一小部分可以在"章节契约"里拦掉。靠润色师救，救不回来。

## 三、写书流程说明书（Stage 0 → Stage 8）

> 总原则：**先定"读者情绪体验"，再造"能生产该体验的设定与人物"，最后才写句子。**
> 顺序不可颠倒。本书的教训就是——句子在前，体验在后，于是词很漂亮，人很空洞。

### Stage 0 · 立项：一句话承诺（开写前必填）

填不出下面4个空，不许开写。**这是全书的"宪法"，后面所有配置都从它推导。**

| 项 | 模板 | 本书示例（正确/错误对照） |
|---|---|---|
| 读者承诺 | 我给读者【持续X】的【情绪】 | ✅"我给读者持续的**智性快感**——看小人物用规则漏洞玩死大佬" ❌"我写一个好看的江湖故事" |
| 差异化卖点 | 别人没有的，我有 | ✅"别人用武功打人，我用**账**杀人" |
| 主循环（读者每章想看什么） | 遇险→找规则漏洞→反杀/脱身→代价 | 必须**可重复**且**每章有变化** |
| 情绪配方 | 各情绪占比（必须有主味） | 智斗50% / 冷幽默20% / 悬疑15% / 温情10% / 悲壮5% |

**验收**：这4条写进项目元数据，且**每一位agent的prompt都注入**。本书缺这条，导致写手只被喂了"机制条目"，没被告知"读者要看智斗"。

### Stage 1 · 世界观：从"设定"到"体验"（规则三问）

**反例（本书的病）**：世界观素材30条，几乎全是"XX机制/XX体系/XX规则"的名词条目。这是**设定集**，不是**世界观**。
设定集只回答"**是什么**"；世界观要回答"**读者能感受到什么**"。

**规则三问（每条核心规则必答）**：

1. **它如何进入角色的日常？**（不是"账目不符是大忌"，而是"我妈的棺材板钱被算进了隔壁王二爷的账上"——**具体到饭碗、棺材、婚书**）
2. **谁在执行？执行成本多大？边界在哪？**（本书"存在抹除"时灵时不灵，就是因为没写清执行者与成本）
3. **它制造的困境长什么样？**（一个好设定 = 一台**困境生产机**，不是一个名词）

**规则卡模板（替代"机制条目"）**：
```
规则名：销籍（账面死亡）
体感：像突然发现自己没有影子——所有人都不承认你存在过
代价：活人身份不可逆；查案要折寿
执行者：户曹印信官（腐败，可被收买——这就是漏洞）
边界/例外：白事堂地下渠道可绕行（本书未写清→矛盾根源）
它逼角色做的选择：苟活（认命） vs 查真相（送死）
能制造的场景：①无身份去当铺 ②被亲人当陌生人 ③给死人办葬礼给自己
```
**验收**：每条核心规则必须能生成≥3个**具体场景**，否则这条设定对写作无价值。

### Stage 2 · 人物：四件套 + 关系网（不许空）

**本书的病**：角色卡 appearance/background/motivation 全空 → AI只能写功能。

**主角四件套（缺一不可，且必须具体到能起冲突）**：

| 件 | 定义 | 本书沈砚（补全版示例） |
|---|---|---|
| 欲望（想要） | 表层目标 | 查清谁销了他的籍，活下去 |
| 恐惧（怕什么） | 深层驱动 | 怕"被算清"——他一生都在替别人算账，怕自己也只是一笔账 |
| 谎言（自我欺骗） | 他信错的东西 | "只要账平了，人就能安稳"（后被现实打碎=成长弧） |
| 创伤/软肋 | 一碰就破防 | 母亲临终那笔没记的账 / 被父亲自愿注销的背影 |

**配角三件套（配角可省"谎言"，但欲望+软肋必须有）**：柳三娘（欲望=找到值得记的账；软肋=算盘上缺的那颗珠）。

**反工具人自检**：把主角从场景里删掉，这个配角**还会不会自己动**？不会，就是工具人。

**关系网**：每两个主要角色之间，用一个**动词短语**定义关系（不是"朋友/敌人"，而是"互相利用又互相看不起""她记得他的恩，他忘了她的仇"）。

### Stage 3 · 大纲：三层结构 + 因果链 + 兑现表

**三层**：卷（大弧光）→ 弧（3-5章一个转折）→ 章（一件事）。

**每章一句话**：必须写成【因为A，所以B，但C】的**因果句**，不是事件句。
- ❌"沈砚去茶肆散谣。"（事件句→第9章降智的根源）
- ✅"因为要被柳三娘当弃子，沈砚只能在**最危险的地方**散谣，逼两派互相咬；但代价是暴露风险，于是他先布局了替身。"（因果句→自带动机和对冲）

**伏笔兑现表**：每个伏笔必须**同时**登记【埋设章】【预期回收章】【回收方式】。
- 本书反面教材：伏笔埋到第26章，书却在第20章收尾 → 大量伏笔烂尾。
- **硬规则：不允许存在"回收章 > 全书规划总章数"的伏笔。** 项目章数变更时，必须重扫伏笔表。

**卷末三件套（防跳时烂尾）**：
1. **不跳时原则**：禁止用"一年后/数月后"跨过高潮的**代价**。要跳时，必须先补一段"代价蒙太奇"（谁死了/主角身上留了什么伤/什么回不去了）。
2. **收束三件事**：主线矛盾怎么解决的（具体手段，不是"推翻了系统"）；主角付出了什么（**必须失去一样他珍视的东西**）；世界变成了什么样（好/坏的**意外后果**）。
3. **结局可行性评估门禁**：写到卷末前，检查"剩余章数 ≥ 未回收伏笔所需的章数"。不够就砍伏笔或加章，**禁止硬切**。

### Stage 4 · 章节工艺：三幕微结构 + 幽默配额制

**单章三幕**（2400-2800字）：
- **第1幕（约15%）**：承接——见 Stage 5「章首三连」。
- **第2幕（约70%）**：一件事，含**至少1次预期违背**（不是打脸，是"我以为X，结果是Y，且Y说得通"）。中间必须有**一次失败或代价**，不能一路顺。
- **第3幕（约15%）**：钩子——但钩子要**轮换类型**（见 §六 6.2），禁止每章都是"真正的麻烦才刚刚开始"。

**幽默配额制（修正 comedy-mandatory 的误用）**：
| 场景类型 | 笑点配额 | 形式 |
|---|---|---|
| 日常/过渡 | 3-4处 | 可外放（吐槽、错位、荒诞） |
| **紧张/危机** | **0-1处** | 只允许**冷面内心OS**，且不能消解张力 |
| 悲壮/高潮 | 0处 | 允许**黑色反差**收尾，禁止玩梗 |
> **核心规则：幽默必须服务于人物或张力，不得"到点交付"。** 本书雨夜讲KPI笑话，就是配额误用。

### Stage 5 · 章首三连（治"衔接断裂"的专用工具）

下一章开头300字内，必须按顺序完成三件事：
1. **承接场景**：上一章最后谁在哪、在干什么（可用一句话过渡）。
2. **承接情绪**：上一章结尾的**最高压力值**（生死威胁/失去/暴怒）必须在本章开头**继续存在或明确消化**。本书第5章的病就是——白主簿的生死威胁**蒸发了**。
3. **承接悬念**：上一章留的钩子，必须在本章**被回应**（哪怕只是"回应了一点点，又起新的"）。

**如果要故意"时间跳跃/场景切换"**，必须**显式交代跳跃原因与代价**，不能默默跳。

### Stage 6 · 文字层：白描优先 + 五不一要

- **白描优先**：具体动作 > 心理形容词 > 比喻。"他捏碎了手里的茶杯，血从指缝里渗出来" > "他内心充满了愤怒"。
- **五不一要**：不排比、不升华收尾、不四字堆叠、不用比喻替代感官、不做说明文旁白；**要具体名词与动作动词**（详见 §五）。
- **对话即人物**：每句台词必须能反推说话人的身份/处境。配角台词不能只有"是/好的/……"（对应元约束M5）。

### Stage 7 · 审读：老书虫五关（打分→门禁）

**阅读体验必须从"打分"升级为"阻断式门禁"**——本书阅读者报告给了7.5分但**没有拦住第9章降智章**，这是最大漏洞。

| 关卡 | 问题 | 不通过动作 |
|---|---|---|
| ①逻辑关 | 角色行为能否用其"欲望/恐惧"解释？道具/场景是否凭空出现？ | **打回重写**（不是润色） |
| ②情绪关 | 紧张处张力有没有被笑话/说明文泄掉？ | 回 Stage4 幽默配额 |
| ③期待关 | 读者对下一章的期待是否被建立且**被回应**？ | 补章首三连 |
| ④新鲜关 | 本章意象/句式/钩子类型是否与前3章重复？ | 回 §六 意象台账 |
| ⑤余味关 | 读完这章，读者会不会想"然后呢"？ | 补结局钩子 |

**门禁规则**：①逻辑关和④新鲜关**任一不通过，本章卡住不进入下一章**。这是本书最需要补的一环。

### Stage 8 · 复盘：把教训变成资产

每卷结束，回填：哪些钩子有效（读者追问）、哪些意象被复用、哪些伏笔烂尾。
**本书的教训应写入 project_memory.md**：如"喜剧配额在紧张场景必须归零""禁止伏笔回收章超出总章数"。

## 四、按类型的元素配置表（"写什么"总纲）

### 4.1 核心公式

> **类型 = 读者承诺 = 情绪配方 = 必备元素 + 主循环 + 节奏 + 禁忌**

配置元素要素时，**不要抄"元素清单"**（有系统、有打脸、有美女），要抄**"情绪配方"**。
写玄幻不是"要有境界"，是"要让读者**持续体验'我变强了'的爽**"。境界只是载体。

### 4.2 五大配置维度（每个项目必填）

| 维度 | 要配置什么 | 配置错误的下场 |
|---|---|---|
| **主情绪** | 读者主要为什么上瘾（爽/悬/燃/甜/笑/怕/暖） | 无主味 → 什么都不深 |
| **主循环** | 可重复的"爽点单元" | 循环不可重复 → 10章后没得写 |
| **节奏公式** | 爽点/悬念的**间隔** | 本书节奏断层=间隔失控 |
| **必备元素** | 该类型的**硬性标志物** | 缺元素=读者觉得"不是这个类型" |
| **禁忌** | 该类型**碰了就掉粉**的东西 | 破禁忌=伤基本盘 |

### 4.3 主流类型配置表（可直接抄进题材Plugin）

| 类型 | 主情绪 | 主循环 | 爽点间隔 | 必备元素 | 致命禁忌 |
|---|---|---|---|---|---|
| **热血升级**（玄幻/仙侠） | 爽（变强/扬眉吐气） | 遇强敌→受挫→得机缘→碾压 | 3-5章一次大爽 | 境界体系、天骄对手、机缘、师门 | 主角长期憋屈、"废柴"开篇过长 |
| **悬疑推理** | 悬（猜不着） | 抛谜→放线索→反转 | 每章1个小反转 | 不可能犯罪、误导项、多重解释 | 线索不给读者就揭晓（作弊） |
| **历史权谋** | 谋（看破人心） | 设局→拆局→反将 | 每2-3章一个局 | 朝堂派系、情报差、人心算计 | 主角开上帝视角、对手降智 |
| **都市异能** | 爽+代入 | 扮猪吃虎→揭身份 | 每2章一个小爽 | 隐藏身份、职场/校园、现实痛点 | 脱离现实、装逼无代价 |
| **言情** | 甜/虐（心跳） | 靠近→误会→和解 | 每章1次情绪波动 | 性格张力、名场面、克制与越界 | 男女主无独立人格、强行误会 |
| **武侠/江湖** | 燃+义 | 恩仇→行走→抉择 | 每3章一场硬仗 | 门派、恩怨、规矩、侠义困境 | 只有打斗没有"规矩"（本书用"账"替代，是加分项） |
| **科幻** | 智+震撼 | 设定→推演→颠覆 | 每卷1个大震撼 | 硬设定、推演链、思想实验 | 设定双标、用魔法解决问题 |
| **喜剧/搞笑** | 笑（放松） | 错位→升级→反转 | 密度高但**场景自适应** | 反差、荒诞逻辑、吐槽 | **紧张处硬抖机灵**（本书之病） |
| **无限流/规则怪谈** | 怕+解谜 | 进场→摸规则→破局 | 每副本1次规则反转 | 明确规则、死亡代价、队友博弈 | 规则随意改、主角开挂 |
| **克苏鲁/诡秘** | 惧+揭示 | 接触→污染→理智 | 慢热，每卷一次崩坏 | 不可名状、代价、知识即污染 | 把克苏鲁写成打怪升级 |

### 4.4 元素的"三层配置"（把一个类型拆成可执行配置）

以**武侠**为例，元素不是一句"有江湖"，要拆成三层：

| 层 | 配置内容 | 本书对应（以账治世） |
|---|---|---|
| **宏观（世界规则）** | 权力来自什么？（武力/金钱/信息/血统） | 账权——权力来自"记账权" |
| **中观（组织与人）** | 有哪些势力，靠什么活，互相什么仇 | 户曹/漕帮/白事堂/苍生局 |
| **微观（场景符号）** | 读者一看到就想到该类型的符号 | 算盘、铜钱、黑信封、彼岸花火漆、账本 |

**配置检查**：读者读前3章，能否**不靠旁白**就说出"这是个什么世界、谁说了算、主角要干嘛"？说不出，就是元素没配到位。

### 4.5 类型元素 vs 本书的复盘

本书类型是"高武 + 反套路喜剧"，配置里 `comedy-mandatory` 要求"每章≥3笑点"。
**问题不在配置存在，在于配置没有"场景分层"**——喜剧类型的笑点密度应该是**曲线**（日常高、危机低、悲壮归零），而不是**直线**（每章均匀3处）。
→ 见 §五 5.4 给出的修正版配置。

## 五、反AI化专章（怎么让文字不像AI写的）

### 5.1 AI味的六大症状（本书全部命中，可当体检表）

| # | 症状 | 本书实例 | 读者体感 |
|---|---|---|---|
| 1 | **段尾强行俏皮话** | "行吧…下面是不是也实行绩效考核制""适合减肥""差评，必须差评" | 出戏、廉价 |
| 2 | **说明文旁白** | "这不是普通的纸。""原来如此。""这哪里是买命单，这分明是…通知书。" | 像作者在划重点 |
| 3 | **抽象升华收尾** | "融入广阔的江湖画卷中，渺小，却又无处不在。" | 空、假、像作文 |
| 4 | **比喻替代感官** | "密集得像一场暴雨前的蝉鸣"（且复用） | 第一次好，第二次腻 |
| 5 | **现代/网络梗乱入古风** | "网上冒充客服""用户体验""可持续发展""SVIP" | 出戏 |
| 6 | **情绪按模板起落** | 每章都"危险→吐槽→转危为安→留钩子" | 可预测、无惊喜 |

### 5.2 六条硬规则（可直接做成detector，对应元约束M1/M4）

| 规则 | 禁止 | 改为 |
|---|---|---|
| **R1 不升华** | 段末/章末拔高抒情（"命运的齿轮开始转动"） | 用**具体动作或物件**收尾（"他把那半截笔杆塞进袖口，像揣着最后一根骨头"） |
| **R2 不解释** | "这哪里是X，这分明是Y""原来如此" | 让读者自己懂；真要提示，用**角色疑惑的动作**代替旁白 |
| **R3 不堆词** | 仿佛/似乎/宛如/不禁/一抹/不由（本书高频） | 换成**具体感官或动作**（"他闻到血腥味"＞"仿佛有血的味道"） |
| **R4 不玩梗** | 紧张场景的段尾俏皮话 | 紧张场景**零笑点**；要幽默就放**日常场景** |
| **R5 不乱入** | 现代词/网络梗（本书"客服/差评/可持续发展"） | 用**世界观内行话**制造幽默（"这算严重的履约失败，该退回外包供应商名单"——同样是幽默，但长在世界里） |
| **R6 不模板** | 每章同一套情绪曲线、同一句钩子话术 | 钩子类型轮换（见 §六 6.2） |

### 5.3 改写示范（本书原文 → 修复版）

**示范A（R4 不玩梗）**
- 原文：雨夜对峙后——"行吧，既然官方都盖章说我是鬼了，那我总得去地府报个到…说不定还能顺便问问，下面是不是也实行绩效考核制。"
- 问题：生死关头讲KPI，张力归零。
- 修复：*"他盯着那两个红字看了很久。雨顺着脖颈往下淌，他忽然觉得冷——不是雨的冷，是那种'原来我真的不存在了'的冷。"*
  （删掉笑点，给出**具体体感**，情绪反而更重。）

**示范B（R2 不解释）**
- 原文："这不是普通的纸。"
- 问题：作者替读者划重点。
- 修复：*"纸片不像纸。他捻了一下，指尖传来兽皮似的粗粝，凑近闻是檀香——檀香是殓房点的那种。"*
  （不告诉"不普通"，用**对比+联想**让读者自己得出"不普通"。）

**示范C（R1 不升华）**
- 原文："阳光正好，影子拉得很长，融入广阔的江湖画卷中，渺小，却又无处不在。"
- 修复：*"他推门出去，日光刺眼，他眯了眯眼。街对面的馄饨摊刚揭锅，白气腾腾——他摸了摸袖子，那本空白的簿子还在。"*
  （用**人间烟火的具体细节**收尾，既落地又留余味。）

**示范D（R5 乱入梗 → 世界观幽默）**
- 原文："这就好比你在网上冒充客服骗人，结果真客服顺着网线爬过来找你喝茶。"
- 修复：*"他借用柳三娘的名头吓退赵四，就像借了别家钱庄的印信去兑银——现在印信的主人，亲自上门兑账来了。"*
  （幽默保留，但**用的是这个世界的货币/账房逻辑**。）

## 六、有趣性专章（怎么让人一看就停不下来）

### 6.1 底层机制：**悬念 - 期待 - 兑现**循环

读者上瘾的不是"信息"，是**"我猜→我急着验证→被打脸但服气"**这个循环。三要素缺一不可：
- **悬念**（不知道结果）：制造"未知"。
- **期待**（想看到某种结果）：制造"我在乎"。
- **兑现**（给出了，且比我想的好）：制造"值了"。

**本书的偏科**：悬念给得多（黑信封、0001、苍生簿），**期待与兑现失衡**——读者被吊着，但兑现经常是"新机制解释"而不是"人物的胜利"，于是越读越疲。

**配置规则**：每章至少完成**一次小兑现**（不能让所有悬念都悬着），大兑现每3-5章一次。

### 6.2 钩子的类型轮换（治"每章都是'真正的麻烦才刚刚开始'"）

**禁止连续两章用同类型钩子。** 六种钩子轮着用：

| 类型 | 示例 | 适用 |
|---|---|---|
| **危险钩** | "身后传来脚步声" | 动作章 |
| **信息钩** | "纸条上只有三个字：别信他" | 悬疑章 |
| **抉择钩** | "保母亲，还是保真相？" | 情感/成长 |
| **反转钩** | "他终于明白——害他的人一直在帮他" | 智斗/揭底 |
| **代价钩** | "他赢了，但那本簿子上的名字变成了他妹妹" | 高潮后 |
| **留白钩** | "他把信看完，烧了。没有告诉任何人信里写了什么。" | 余味 |

### 6.3 意象台账（治"陈年腐臭/暴雨蝉鸣"复用）

建一张表，登记全书已用过的**强意象**，每个意象**全书只允许出现一次**（或间隔≥30章且换角度）。

| 意象 | 首次使用章 | 状态 |
|---|---|---|
| 算盘声=暴雨前蝉鸣 | 第3章 | 🔒已锁定，禁用 |
| 码头腥臭=陈年腐臭 | 第1章 | 🔒已锁定 |
| 雨夜"分不清雨还是汗" | 第1章 | 慎用，全书≤2次 |

**替代法**：同一地点第二次去，写**它变了什么**，而不是复用第一次的描写。例：
- 第一次进档案室："干燥的灰尘与墨汁味。"
- 第二次进档案室（已废弃）："灰尘里多了股尿骚味——有人在这儿躲过雨。"

### 6.4 开篇三章公式（决定读者留不留）

| 章 | 任务 | 本书表现 |
|---|---|---|
| 第1章 | **30秒内**给出"主角的困境+一个反常举动+一个谜" | ✅合格（销籍+夺账本+黑信封） |
| 第2章 | 展示**主角的行事方式**（他怎么解决问题） | ✅合格（用规则吓退赵四） |
| 第3章 | 抛出**贯穿全书的"主悬念"**，并给一个**小爽点** | △一般（主悬念"苍生局/0001"埋了，但没有小兑现） |

**开篇铁律**：前1000字必须出现三样——**冲突、信息差、反常**。缺一读者就走。

### 6.5 让"智斗"真的好看（本书的强项，但仍可提升）

智斗好不好看，取决于**两件事**：
1. **对手的威胁必须真实**（不能是真傻子）。赵四被吓退很爽，但赵四是**莽夫**，读者爽完不长记性。真正的智斗名场面，是**两个聪明人互相猜**。
2. **主角的胜利必须有代价**。第1章沈砚零代价脱身——爽是爽，但不揪心。**代价越重，爽感越高级**。

**规则**：每3次"无代价小胜"，必须跟1次"有代价大胜"。

## 七、落地到 novel-pipeline（把"工艺"变成"配置+门禁"）

> 工艺不落到管线，就只是读后感。以下每条都对应本仓库可改的位置。

### 7.1 素材层：角色卡四件套硬门禁

- **现状**：`tmp_ent.json` 里角色 `appearance/background/motivation` 全空，契约只查"深度字段是否存在"。
- **改造**：
  1. `characterDepthExtractor` / 契约校验增加**非空且非模板化**判断：`motivation` 为空的主角/主要配角 → **CRITICAL 阻断**。
  2. 主角卡必须含 §三 Stage2 四件套（欲望/恐惧/谎言/创伤），配角含三件套（省"谎言"）。
  3. 世界观素材从"机制条目"改为**规则卡模板**（§三 Stage1），并校验每条规则能生成≥3个具体场景。

### 7.2 约束层：修正 comedy-mandatory，新增三条元约束

- **修改** `constraintPresets.js` 的 `comedy-mandatory` → `comedy-adaptive`（§五 5.4）。
- **新增元约束（补进 08 的 T0 清单；08 现为M1-M5）**：
  | ID | 元约束 | 检测模式 |
  |---|---|---|
  | **M6** | 紧张/悲壮场景禁止段尾玩梗与情绪消解 | 检测"高张力句"后紧跟"俏皮话"的模式 |
  | **M7** | 禁止段末/章末抽象升华抒情 | 检测段尾"渺小/命运/画卷/齿轮/终于明白"类升华句 |
  | **M8** | 章首必须承接上章末的**压力值**（不只是场景） | 比对前章末**情绪峰值**与本章首300字 |
- **说明**：M3（章节衔接）只管"场景/动作"，M8 管"情绪/威胁"，两者互补。本书第4→5章的断裂，M3 查不出，M8 能查。

### 7.3 检测层：补 4 个 detector

| 新 detector | 治什么 | 触发规则 |
|---|---|---|
| `detectBanterDeflation` | 张力消解 | 紧张段落后接俏皮话/网络梗 |
| `detectAbstractEnding` | 升华收尾 | 段尾/章尾出现"渺小/命运/画卷/齿轮/终将/注定" |
| `detectMotifReuse` | 意象复用 | 语义相似（非逐字）的高频意象/比喻≥2章重复 |
| `detectHookMonotony` | 钩子同质 | 连续2章结尾钩子属同一类型（用§六6.2六类判定） |

### 7.4 审核层：阅读者从"打分"升级为"门禁"

- **现状**：阅读者报告给分（7.5/6.5）+ `wantToContinue`，但**不阻断**——第9章降智、第16章伏笔断裂都被"记录"却放行。
- **改造**：把"逻辑关/新鲜关"设为**hardBlock**（§三 Stage7）。具体：
  - `hardIssues` 中出现 `logic-flaw` / `character-break` / `setting-conflict` / `foreshadow-forgot` → **本章不通过，自动回退重写**（不是润色）。
  - `repetition-pattern` 累计2次 → 强制去重。
  - `overallScore < 6.0` 或 `wantToContinue=false` → **卷末门禁告警**，必须在下一卷前修。

### 7.5 结构层：伏笔兑现表 + 结局可行性门禁

- 伏笔登记表增加字段【回收章】，并在**项目章数变更时自动重扫**：存在"回收章 > 总规划章数"的伏笔 → **CRITICAL 告警**（本书伏笔埋到26章、书20章收尾的直接原因）。
- 卷末前触发**结局可行性评估**（§三 Stage3）：剩余章数 ≥ 未回收伏笔所需章数，否则禁止收尾。

### 7.6 立项层：把"读者承诺/情绪配方"写进项目元数据并注入所有agent

- 每个项目新增4字段（§三 Stage0：读者承诺/差异化卖点/主循环/情绪配方）。
- `agentPromptAssembler` 将其注入 writer/reviewer 的 prompt 首部——**让写手知道读者要什么**，而不是只拿到一堆设定条目。
