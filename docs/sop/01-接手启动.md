## 一、绝对规则（违反=停止并报告）

1. **FAILED不是正常** — preflight/postflight/pollution检查的任何FAILED必须追查根因，禁止"正常降级"借口
2. **genre=null是裸奔** — 无genre=无约束=输出必偏移，必须修复后再继续
3. **统一用resolveGenreFromProject(project)** — 禁止直接detectGenre(project.styleProfile)
4. **端到端验证必须** — 代码改动后必须用真实项目数据验证，不能只靠单元测试
5. **禁止"应该没问题"** — 无法验证=未完成，必须明确说明已验证和未验证部分

## 四、genre检测规范

### 4.1 统一入口
```js
// ✅ 正确
const genreId = resolveGenreFromProject(project);

// ❌ 禁止
const genreId = detectGenre(project?.styleProfile);
const genreId = getGenrePlugin(project.genre);
```

### 4.2 检测优先级
1. `project.subGenre` 或 `project.subgenre` → `getGenreById()`
2. `project.styleProfile` → `detectGenre()`
3. `project.genre` → `getGenreById()` 然后 `detectGenre({genre})`

### 4.3 项目styleProfile Schema
```json
{
  "key": "high-martial-comedy",
  "genre": "高武穿越·诸天万界",
  "genreProfile": "高武穿越",
  "style": "反套路喜剧",
  "tone": "白描+冷面吐槽",
  "pov": "紧贴男主局外人+吐槽役视角"
}
```

### 4.4 subGenre字段规范
- 必须用驼峰 `subGenre`（不是 `subgenre`）
- 值必须是题材插件ID（如 "high-martial-comedy"），不是中文名
- 代码必须同时兼容 `subGenre` 和 `subgenre`（旧数据）
- 题材白名单由 `scripts/audit-genre-whitelist.js` CI强制校验，仅 `high-martial-comedy` 和 `baby` 可用

## 五、已知反模式（必须避免）

- ❌ `detectGenre(project.styleProfile)` — 格式不匹配返回null
- ❌ `getGenrePlugin(project.genre)` — project.genre是中文字符串不是styleProfile对象
- ❌ 把审核拒绝当正常 — qwen3.6-plus很强，拒绝=prompt有问题
- ❌ 代码改动后跳过端到端验证

---

## 六、关系阶段守卫

- writer和reviser的prompt必须包含关系阶段守卫
- 守卫注入在prompt最前面，先于其他指令
- 优先级：关系阶段 > 风格规则 > 题材规则 > 默认规则
