# 题材插件开发SOP

> 触发条件：新增/修改题材Plugin
> 前置：已读 [00-陷阱清单.md](00-陷阱清单.md)
> 完整规范见 [reference/题材插件规范.md](../reference/题材插件规范.md)

---

## 一、5步开发流程

```
第1步：确定素材类型 → 填 materialFocus (primary/secondary/skip)
第2步：确定Agent权限 → 填 agentMaterialAccess (10个Agent × needs+detail)
第3步：填写其余字段 → foundation/styleProfile/genreBase/reviewRules/detectors/interceptors...
第4步：运行验证 → 启动时validateGenre()，确保0错误0警告
第5步：创建项目测试 → 前端创建项目，跑Pipeline验证
```

---

## 二、素材类型速查（materialFocus）

| 类型 | 适用题材 | 分类建议 |
|------|---------|---------|
| character/relationship/worldview/foreshadowing | 所有 | primary |
| catchphrase/famous-scene | 所有 | primary或secondary |
| power-system/equipment/faction/craft | 玄幻/系统/异能 | primary或secondary |
| mechanism | 无限流/科幻 | primary |
| sub-plane/institution | 高武 | primary或secondary |
| location | 都市/玄幻 | secondary |
| growth-history | 萌娃/养成 | primary |
| writing-technique/character-combat | 都市异能/符师 | secondary |

**分类规则**：primary=必须生成详细 / secondary=按需中等 / skip=禁止生成

---

## 三、Agent权限分工（agentMaterialAccess）

| Agent | detail | needs范围 |
|-------|--------|----------|
| writer/reviser/material-manager | full | primary + secondary 全部 |
| polisher/intent-planner/first-review/second-review/final-editor/reader | summary | 核心3-6种 |
| fast-review | index | 核心2-3种 |

**核心原则**：needs 只能包含 primary + secondary，绝不包含 skip。

---

## 四、必填字段清单（第3步）

| # | 字段 | 说明 |
|---|------|------|
| 1 | reviewRules | 4个子项(perspectiveRule/terminologyRule/outputRule等)，每个字段必须填 |
| 2 | detectors | 至少3个(perspective/terminology/modernSlang) |
| 3 | interceptors | 2个(firstReview/secondReview) |
| 4 | constraintPresets | 题材特有约束预设 |
| 5 | dedupRules | 防止prompt膨胀的去重规则 |
| 6 | qualityChecks | 根据题材启用/禁用特色检测 |
| 7 | perspectiveSchema | 萌娃类用baby/adult/mixed，其他用protagonist/narrator/other |
| 8 | styleProfile | 6个规则字段(povRule/dialogueRule/behaviorRule/toneRule/titleRule/characterRefRules) |
| 9 | genreBase | 4个追加规则(BEHAVIOR_APPEND/TONE_APPEND/REVIEW_APPEND/REQUIRED_CONSTRAINT_OVERRIDES) |
| 10 | incompatibleConstraints | 排除与本题材矛盾的通用约束 |
| 11 | requiredConstraints | 本题材必须加载的约束 |

## 五、验证清单

### 5.1 自动验证（启动时）
- [ ] validateGenre() 输出 "✅ 题材插件验证通过"
- [ ] 无必填字段缺失
- [ ] agentMaterialAccess 覆盖10个Agent
- [ ] needs 无 skip 类型
- [ ] 无未知字段

### 5.2 手动验证命令
```bash
# 1. 语法检查
node -c server/services/genres/<genre-id>.js

# 2. 注册+验证检查
node -e "const g=require('./services/genres/<genre-id>'); console.log(g.id, Object.keys(g.agentMaterialAccess).length+' agents')"

# 3. 完整加载检查
node -e "require('./index')"
```

### 5.3 端到端验证
1. 重启服务器
2. 打开题材调试面板（/genre-debug），检查每个Agent的素材访问和提示词
3. 前端创建项目，选择对应风格配置
4. 系统自动匹配题材插件（通过 patterns 关键词）
5. 启动 Pipeline，观察日志

### 5.4 检查清单
| # | 检查项 | 预期结果 |
|---|--------|---------|
| 1 | validateGenre() | ✅ 通过 |
| 2 | 素材库内容 | 只有 primary + secondary，无 skip |
| 3 | 素材命名 | catchphrase用原文、famous-scene用场景名 |
| 4 | Agent日志 | writer/reviser加载full，fast-review加载index |
| 5 | 约束日志 | constraintInjector输出 "removed N constraints" |
| 6 | 审核日志 | interceptor检测正常，无误杀 |
| 7 | 题材调试面板 | 每个Agent提示词无Error |

## 六、关键约束

1. **题材检测统一入口**：所有代码用resolveGenreFromProject(project)，禁止detectGenre(project?.styleProfile)（见陷阱#23）
2. **约束统一注入**：通过constraintInjector统一注入，禁止独立调用buildGenreOutlineInjection
3. **HARD BLOCK必须**：甜宠等题材必须有HARD BLOCK防止偏移（见陷阱#17）
4. **文件放置**：新题材.js放入 `server/services/genres/` 目录自动注册生效
5. **完整规范**：Agent职责/记忆系统/约束系统/上下文预算/Plugin接口详见 [reference/题材插件规范.md](../reference/题材插件规范.md)

- 素材类型新增 → 追加到第二节素材类型速查

- 必填字段清单变化 → 更新第四节
- 验证清单有新项 → 追加到第五节
- 题材插件相关新陷阱 → 追加到 [00-陷阱清单.md](00-陷阱清单.md) 题材类
